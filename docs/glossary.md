# 용어집 (glossary)

게임 화면에 보이는 문구 기준의 번역 용어입니다. 사전 파일 i18n/ko.json과 함께 맞춰 관리합니다.

| 원문 | 한국어 | 비고 |
|---|---|---|
| 赤龍 Crimson Loong | 적룡(赤龍) Crimson Loong | 제목. 원문 표기 유지 |
| loong | 룽 (중국식 용) | 원작 명칭 뜻 유지 |
| dragon | 용 | 장면의 주인공 |
| film | 영상 | 게임이 스스로를 film이라 부름 |
| sound | 소리 | 소리 켜기/끄기 |
| tuning | 조율 중 | 로딩 및 음악 준비 |
| erhu | 얼후 | 중국 전통 현악기 |
| waking | 깨어나는 중 | 로딩 상태 |
| paused | 일시정지 | Space 키 정지 상태 |
| graphics context | 그래픽 컨텍스트 | 기술 용어 유지 |
| WebGL 2 | WebGL 2 | 고유 명칭, 번역 안 함 |
| float render targets | float 렌더 타깃 | 기술 용어 유지 |

## 원칙

- 원문은 HTML과 JS에 그대로 두고, 표시 시점에만 사전 값으로 바꿉니다.
- 같은 원문은 항상 같은 번역을 씁니다.
- 기술 용어(WebGL, float 등)와 고유 명칭은 영문을 유지합니다.
